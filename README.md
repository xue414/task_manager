This Personal Task Management System enables users to efficiently manage tasks (add, delete, mark as done, sort by priority). It integrates tools like `flake8` (code linting), `black` (code formatting), `pytest` (testing), Docker (for deployment), and GitHub Actions (for CI/CD). It uses `.env` for secrets (e.g., database config) and proper ignore files (`.gitignore`, `.dockerignore`) for streamlined development.
